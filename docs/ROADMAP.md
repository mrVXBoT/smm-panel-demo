# Roadmap
Each phase is independently reviewable and must meet quality gates.
- P00 Foundation: Vite React TS, tooling, CI, feature folders, app router.
- P01 Design: tokens, components, dark/light, responsive shell, accessibility.
- P02 Public/Auth: landing, catalog teaser, pricing, FAQ, demo login and role switch.
- P03 Client: dashboard KPIs, charts, profile, seeded activity.
- P04 Catalog: categories, filters, product cards, virtual numbers, Stars, Premium.
- P05 Orders: dynamic forms, validation, pricing, status lifecycle, history.
- P06 Payments: simulated Visa/Mastercard, ledger, wallet, fake receipts, failure/refund.
- P07 Admin: services, users, orders, payments, tickets, settings.
- P08 Extras: referral, notifications, mock API docs, i18n.
- P09 QA: end-to-end journeys, responsive audit, a11y, reset, release.
## Definition of Done
Acceptance criteria met; no real payment or provider calls; tests and build pass; mobile and desktop verified; demo labels visible.
