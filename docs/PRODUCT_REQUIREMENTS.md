# Product Requirements — SMM Panel Demo
## Goal
A fully interactive, self-contained demo for sales presentations. No backend, domain, real payment processor or delivery provider required.
## Audiences
Visitor, demo customer, demo administrator. Roles are UI simulations, not security boundaries.
## Public
Landing, service overview, pricing, FAQ, sign-in/sign-up mock, legal/demo disclosure.
## Customer
Overview, service catalog, new order, orders/history/detail, wallet/add funds, transactions/receipts, support tickets, profile, referral, sample API documentation.
## Service categories
Telegram subscribers, post views, reactions, boosts, Stars, Premium; fictional virtual numbers; optional Instagram/TikTok/YouTube demonstration products.
## Order forms
Service-dependent fields; link/username, quantity, country/platform where applicable. Validate ranges and compute totals. Show confirmation and lifecycle Pending > Processing > Completed or Failed/Refunded.
## Wallet & checkout
Mock Visa/Mastercard selection, preset test amounts, simulate success/failure/cancel, append ledger events, issue fake receipts. Never accept real card details.
## Admin
KPIs, manage demo services, orders, users, mock payments, support, configuration and audit trail.
## Non-functional
Mobile-first, accessible, RTL-ready, seed/reset, persistence across refresh, zero external credentials, explicit demo watermark.
## Out of scope
Real cards, payment authorization, real phone provisioning, SMS/OTP capture, live SMM provider APIs, production authentication.
