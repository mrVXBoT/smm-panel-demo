# Design System
## Direction
Premium SaaS fintech-inspired SMM dashboard, crisp dense data presentation, calm surfaces and selective cyan accents.
## Palette
Dark background #0B1120, dark surface #111B2E, elevated #18263D, primary #38BDF8, text #F1F5F9, muted #94A3B8. Light background #F8FAFC, surface #FFFFFF, text #0F172A. Semantic: success #22C55E, warning #F59E0B, danger #EF4444.
## Typography
Inter for Latin; Vazirmatn for Persian. Fluid hierarchy, 14–16px body, tabular numerals for financial amounts.
## Layout
Desktop sidebar 256px, topbar 64px, max content 1440px; mobile bottom navigation or drawer. 8px spacing scale; card radius 16px; inputs 10px.
## Components
AppShell, Sidebar, Topbar, KPI cards, ServiceCard, ServiceSelector, OrderForm, StatusBadge, DataTable, EmptyState, Skeleton, ConfirmDialog, Toast, WalletCard, DemoCheckout, Receipt.
## Interaction
Visible focus rings, keyboard-friendly dialogs, responsive tables, subtle 120–200ms transitions. Loading, empty, error and success states for all flows.
## Demo disclosure
Persistent DEMO badge; checkout states clearly say simulation, not a real card payment. Never imitate a real bank's credential collection form.
